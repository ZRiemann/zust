根 package =zust= 的 library 名称为 =z=，公开入口统一为 =z::xxx=。
只有门面使用这个库名；独立组件保留唯一名称，例如 =zust_log=。
门面通过 feature 按需重导出，默认不启用任何组件。
依赖方向为门面到组件、组件到 Forge 批准的第三方 crate；组件不依赖门面或下游业务。

在项目根目录执行 =./zbuild.py dev logging --profile debug=，即可编译并运行一次
显式选择的日志示例，默认只输出控制台。文件配置和完整命令见
[[file:logging.org][日志使用说明]]及 [[file:../../BUILD.org][构建指南]]。
