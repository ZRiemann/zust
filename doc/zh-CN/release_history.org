*** 变更
- 建立由 Forge 治理的 Rust workspace，门面 package zust 的 library 名为 z，
  默认不启用组件，通过 feature 提供 z::log。
- 新增独立 zust-log，使用固定版本 spdlog-rs，实现 zpp 配置和文本/JSONL 适配、
  important 独立路由、有界异步背压、调用者元数据及显式排空/刷新/关闭归属。
- 补齐双语使用与运行文档、配置 fixture、组件/门面/重命名消费者验证和显式微基准。
- 将 logging Cargo 示例注册为 zbuild 显式目标，复用 Forge 的示例选择、profile
  产物及仓库根目录运行支持。默认库目标不变；run 使用已有产物，dev 先构建。

*** 兼容性
- 轮转文件直接使用后端默认命名。支持范围内的合法 zpp 配置可复用；非法已知字段、
  不支持的 pattern 功能明确报错。
- 保留 Rust 源码/模块路径约定，全部通道使用同一配置的基础 logger 名称。
  精确兼容边界见日志指南。
