The root =zust= package exposes library =z=. Component crates have unique names
and independent responsibilities. Dependencies point from the facade to
components, and from components to Forge-approved third-party crates; component
code never depends on the facade or a downstream application's business policy.

To try logging, use =./zbuild.py dev logging --profile debug= from the project
root. This builds and runs the explicitly selected example once, using console
output. See [[file:logging.org][logging usage]] and [[file:../../BUILD.org][build commands]] for file configuration.
