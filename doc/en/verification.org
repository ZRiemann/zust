* Bounded Release microbenchmark

Command: =cargo bench --locked -p zust-log --bench logging -- --run=.
Each case warms up 2,000 records, then samples 50,000 calls on one producer.
Enabled cases use the same backend size-rotating buffered file sink settings,
message plus newline, no periodic/level flush, and no rotation during the run.
The benchmark verifies identical native/wrapped output after final flush.
Temporary files are owned by the benchmark and removed on success.

| Case | Calls/second | P50 ns | P99 ns |
|------+--------------+--------+--------|
| Native enabled | 6,229,905 | 135 | 245 |
| zust enabled | 3,421,618 | 265 | 323 |
| Native disabled | 31,712,306 | 14 | 16 |
| zust disabled | 29,997,510 | 16 | 22 |

One local run; not a statistical performance guarantee. Measurement includes
clock sampling and sample collection. The enabled difference includes metadata,
routing, compatibility formatting and lifecycle synchronization. Facade
re-export itself adds no runtime work. This does not measure the default full
text pattern, important JSONL, asynchronous throughput, saturation latency,
fsync or sustained disk performance. Default correctness tests skip measurement.
